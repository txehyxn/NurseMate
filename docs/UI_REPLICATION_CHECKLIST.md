# NurseMate UI Replication Checklist

첨부 시안을 복제하는 모든 UI 작업에서 사용하는 완료 전 체크리스트다.

## 1. 비교 조건

- [ ] 기준 시안 파일과 대상 화면을 명시했다.
- [ ] 시안과 동일하거나 대응되는 화면 크기로 렌더링했다.
- [ ] 모바일을 먼저 확인하고 태블릿·웹 확장도 확인했다.
- [ ] 현재 화면과 시안을 나란히 비교했다.

## 2. Header

- [ ] 전체 높이와 상하 여백이 일치한다.
- [ ] 로고 크기와 기준선이 일치한다.
- [ ] 알림 및 프로필의 크기와 위치가 일치한다.
- [ ] 제목과 설명의 글자 크기·두께·행간이 일치한다.

## 3. Calendar

- [ ] 카드 전체 크기, 반경, Padding이 일치한다.
- [ ] 월 이동 버튼과 월 제목 위치가 일치한다.
- [ ] 요일과 날짜의 열 너비·행 높이가 일치한다.
- [ ] 오늘 표시 원형의 크기와 색상이 일치한다.
- [ ] 근무 Badge의 크기, 위치, 색상이 일치한다.
- [ ] 범례의 순서와 간격이 일치한다.

## 4. Card 및 Feature Card

- [ ] Radius가 24~28px 범위의 기존 토큰을 사용한다.
- [ ] Border와 Shadow가 시안만큼 은은하다.
- [ ] 카드 사이 Margin과 내부 Padding이 일치한다.
- [ ] 아이콘·일러스트의 크기와 위치가 일치한다.
- [ ] 제목·설명·화살표 버튼의 기준선이 일치한다.
- [ ] 모바일 열 개수를 시안과 동일하게 유지한다.

## 5. Typography

- [ ] 제목·본문·설명·숫자의 크기 계층이 일치한다.
- [ ] FontWeight, letterSpacing, lineHeight가 일치한다.
- [ ] 줄바꿈 위치와 최대 줄 수가 시안과 유사하다.
- [ ] 네이비 본문과 회색 설명 색상을 토큰으로 사용한다.

## 6. Controls

- [ ] 버튼은 NurseMate Gradient와 Radius를 사용한다.
- [ ] 입력창은 NurseMate Border, Padding, Focus 스타일을 사용한다.
- [ ] Dialog, FAB, Search, Tab을 Material 기본 모양으로 노출하지 않는다.
- [ ] 터치 영역은 최소 44×44px이다.

## 7. Bottom Navigation

- [ ] 높이, 흰색 배경, 상단 경계가 일치한다.
- [ ] 5개 메뉴의 간격과 아이콘 크기가 일치한다.
- [ ] 선택된 메뉴의 연보라 배경과 Primary 색상이 일치한다.
- [ ] SafeArea에서도 시안의 비율이 유지된다.

## 8. Animation

- [ ] 기본 동작은 250~350ms이다.
- [ ] `easeOutCubic`을 사용한다.
- [ ] Fade, Scale, Slide가 기존 화면과 같은 강도로 동작한다.
- [ ] 갑작스러운 전환이나 과한 애니메이션이 없다.

## 9. 기능 보호 및 검증

- [ ] 수액 계산과 방울 애니메이션이 유지된다.
- [ ] 메모·사진·형광펜 저장이 유지된다.
- [ ] 듀티·약 검색·잠금 기능이 유지된다.
- [ ] `flutter analyze` 오류가 0개다.
- [ ] `flutter test`가 전체 통과한다.
- [ ] `flutter build web`이 성공한다.

## 10. 완료 보고

- [ ] 화면 영역별 일치 결과와 남은 차이를 기록했다.
- [ ] 실제 비교 없이 임의의 유사도 퍼센트를 작성하지 않았다.
- [ ] 정량 유사도를 보고했다면 화면 크기와 산정 근거를 포함했다.
